검증된 기능

일괄 프리셋

여러 사진에 IPTC 프리셋을 재사용하면서 사진별 재정의도 유지합니다.

해결하는 문제: 반복 작업에서 같은 필드를 사진마다 다시 입력하면 일관성을 유지하기 어렵습니다.

할 수 있는 작업

  • 메타데이터 템플릿 또는 프리셋을 만들어 재사용하기
  • 선택한 여러 사진에 일괄 값을 적용하기
  • 한 사진에 다른 캡션이나 필드 값이 필요할 때 사진별로 재정의하기

사용 가능한 옵션

  • 프리셋 필드, 일괄 값, 사진별 재정의, 작성자, 위치와 전달 설정

지원 입력

  • 선택한 로컬 사진 묶음과 저장된 메타데이터 프리셋

출력

  • 해결된 메타데이터 값이 들어간 처리된 사진 사본 묶음

작업 흐름

  1. IPTC 프리셋을 선택하거나 만듭니다
  2. 처리할 일괄 필드와 사진을 선택합니다
  3. 사진별 재정의를 검토하고 최종 값을 처리된 사본에 기록합니다

제한 사항

  • 프리셋은 해당 작업 흐름에 설정된 필드만 변경하며, 비어 있거나 비활성화된 필드에 값이 있다고 간주하지 않습니다.

자주 묻는 질문

사진 한 장이 일괄 메타데이터를 재정의할 수 있나요?

예. 작업 흐름 해석 테스트는 설정된 필드에서 사진별 값이 일괄 값보다 우선하는 동작을 다룹니다.
