검증된 기능

IPTC, EXIF, XMP 편집

캡션, 제목, 키워드, 작성자, 저작권, 권리와 위치 메타데이터를 확인하고 편집합니다.

해결하는 문제: 사진마다 캡션, 크레딧, 권리 또는 키워드를 다르게 편집하면 전달 내용이 일관되지 않을 수 있습니다.

할 수 있는 작업

  • 지원되는 EXIF, IPTC, XMP 메타데이터를 읽고 확인하기
  • 캡션, 제목, 키워드, 작성자, 저작권, 권리와 위치 필드를 처리한 사진 사본에 쓰기
  • 사진별 값으로 일괄 값을 세밀하게 조정하거나 재정의하기

사용 가능한 옵션

  • IPTC 기본·확장 필드, XMP 필드, EXIF 처리와 위치 값

지원 입력

  • Android 기기에서 선택한 로컬 사진 파일

출력

  • 선택한 메타데이터를 기록한 처리된 사진 사본

작업 흐름

  1. 사진 한 장 또는 여러 장을 선택합니다
  2. 프리셋을 선택하거나 캡션, 제목, 키워드, 작성자와 권리 정보를 입력합니다
  3. 결과를 확인하고 처리된 사본을 저장합니다

제한 사항

  • 사용 가능한 필드와 기록 동작은 선택한 파일과 작업 흐름에서 활성화한 필드에 따라 달라집니다.

자주 묻는 질문

CaptionMeta는 Android에서 IPTC와 XMP를 편집하나요?

예. 현재 사진 메타데이터 작업 흐름에는 IPTC와 XMP 기록 코드 및 검증 테스트가 포함되어 있습니다.
