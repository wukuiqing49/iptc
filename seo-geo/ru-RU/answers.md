# CaptionMeta answer brief (ru-RU)

## Редактирование IPTC, EXIF и XMP

Передача фотографий становится непоследовательной, если подписи, авторство, права и ключевые слова редактируются по-разному для каждого изображения.

### Можно ли редактировать IPTC и XMP на Android с помощью CaptionMeta?

Да. Проект содержит запись IPTC и XMP, а также тесты проверки текущего процесса работы с метаданными.

## Очистка личных метаданных

Фотография может содержать местоположение, данные камеры и другие метаданные, которые не нужно включать в каждую передачу.

### Изменяет ли очистка исходную фотографию?

Документированный процесс создаёт обработанные данные для передачи. При необходимости сохраните оригинал и проверьте сохранённый результат.

## Шаблоны для пакетной обработки

При повторяющихся заданиях трудно сохранять единообразие, если одни и те же поля заново вводятся для каждой фотографии.

### Может ли одна фотография заменить пакетное значение?

Да. Тесты разрешения процесса подтверждают приоритет значения отдельной фотографии над настроенным пакетным значением.

## Очередь передачи фотографий

Передача фотографий с места может завершиться ошибкой, если файлы, серверные настройки и повторы управляются отдельно.

### Какие протоколы передачи поддерживаются?

Модуль загрузки содержит клиенты и модели настройки для FTP, FTPS, SFTP, HTTP, SMB и WebDAV.
