Android写真ツール

CaptionMeta

現場で使える写真メタデータ。

CaptionMetaはAndroid向けの写真メタデータツールです。IPTC、EXIF、XMPの項目を確認・編集し、プリセットを再利用して、非公開メタデータを整理した写真コピーを納品できます。

アプリを見る

接続されたAndroid端末で取得した実際のアプリ画面です。

撮影から納品までのメタデータワークフロー

現在のAndroidソースコード、テスト、インストール済みアプリ画面で確認できる機能です。

IPTC、EXIF、XMPの編集

キャプション、見出し、キーワード、署名、著作権、権利、位置情報を確認・編集します。

写真コピーを共有する前に、選択したEXIF、IPTC、XMPデータを確認して削除します。

Explore this feature →

写真納品キュー

処理した写真をキューに入れ、設定済みサーバーへ納品して結果を確認します。

Explore this feature →

モバイル写真ワークフローに対応

メタデータ入力、プライバシー確認、ファイル納品を1つのAndroidツールにまとめます。

  1. 写真を撮影するか、端末内の画像を選択します。
  2. プリセットを選び、キャプション、キーワード、クレジット、権利情報を入力します。
  3. 必要に応じて写真ごとの値を上書きし、一括処理します。
  4. 結果を確認し、処理したファイルを納品キューに追加します。
