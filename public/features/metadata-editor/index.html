IPTC、EXIF 与 XMP 编辑

查看并编辑说明、标题、关键词、署名、版权、权利和位置等照片元数据。

解决什么问题: 当每张照片的说明、署名、权利或关键词都被单独编辑时，交付内容容易不一致。

可以完成什么

  • 读取并检查支持的 EXIF、IPTC 和 XMP 元数据。
  • 将说明、标题、关键词、署名、版权、权利和位置写入处理后的照片副本。
  • 使用单张照片的值细化或覆盖批量值。

可配置选项

  • IPTC 核心与扩展字段、XMP 字段、EXIF 处理和位置值。

支持的输入

  • 从 Android 设备选择的本地照片文件。

生成的结果

  • 写入所选元数据字段的处理后照片副本。

操作流程

  1. 选择一张或一组本地照片。
  2. 选择预设，或填写说明、标题、关键词、署名和权利字段。
  3. 检查结果并保存处理后的副本，用于分享或交付。

使用限制

  • 可用字段和写入行为取决于所选文件以及工作流中启用的元数据字段。

常见问题

CaptionMeta 能在 Android 上编辑 IPTC 和 XMP 吗？

可以编辑支持的 IPTC 与 XMP 字段。具体可用字段取决于文件格式和工作流设置，请在保存后检查结果。
