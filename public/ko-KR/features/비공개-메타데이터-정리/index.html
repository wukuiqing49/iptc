비공개 메타데이터 정리

사진 사본을 공유하기 전에 선택한 EXIF, IPTC, XMP 데이터를 확인하고 삭제합니다.

해결하는 문제: 사진에는 위치, 카메라와 기타 메타데이터가 포함될 수 있어 모든 전달에 넣어야 하는 것은 아닙니다.

할 수 있는 작업

  • 추적되는 EXIF, IPTC, XMP 메타데이터 범주를 확인하기
  • 처리된 사진 사본에서 선택한 비공개 메타데이터를 제거하기
  • 원본 파일과 정리된 출력 흐름을 분리하기

사용 가능한 옵션

  • 위치, 카메라와 정리 흐름에서 추적하는 기타 메타데이터 범주

지원 입력

  • EXIF, IPTC 또는 XMP 메타데이터가 있는 로컬 사진

출력

  • 선택한 메타데이터를 제거한 처리된 사진 사본

작업 흐름

  1. 확인할 사진을 선택합니다
  2. 정리할 수 있는 메타데이터 범주를 검토합니다
  3. 정리를 실행하고 처리된 사본을 전달에 사용합니다

제한 사항

  • 정리 범위는 현재 앱 버전에 구현된 메타데이터 범주를 기준으로 하므로 게시 전에 출력 결과를 확인하세요.

자주 묻는 질문

정리하면 원본 사진이 바뀌나요?

문서화된 흐름은 전달을 위한 처리된 사진 데이터를 만듭니다. 필요하면 원본을 보관하고 저장된 결과를 확인하세요.
