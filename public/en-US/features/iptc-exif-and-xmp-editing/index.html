IPTC, EXIF, and XMP editing

Review and edit captions, headlines, keywords, bylines, copyright, rights, and location metadata.

The problem it solves: Photo handoffs become inconsistent when captions, credits, rights, or keywords are edited differently for every image.

What you can do

  • Read and inspect supported EXIF, IPTC, and XMP metadata.
  • Write captions, headlines, keywords, bylines, copyright, rights, and location fields into processed photo copies.
  • Use per-photo values to refine or override batch values.

Available options

  • IPTC core and extended fields, XMP fields, EXIF handling, and location values.

Supported inputs

  • Local photo files selected from the Android device.

Outputs

  • Processed photo copies with the selected metadata fields written.

Workflow

  1. Select a local photo or group of photos.
  2. Choose a preset or enter captions, headlines, keywords, bylines, and rights.
  3. Review the result and save the processed copy for sharing or delivery.

Limitations

  • Available fields and write behavior depend on the selected file and the metadata fields enabled in the workflow.

Common questions

Can CaptionMeta edit IPTC and XMP metadata on Android?

You can edit supported IPTC and XMP fields. Available fields depend on the file format and workflow settings; check the generated file.
