如何在 Android 照片中添加说明、署名与版权

让接收照片的人知道拍了什么、由谁拍摄，以及应该如何署名。先区分字段的用途，再检查生成文件中的实际内容。

当前版本 1.4.0 · 2026-11-12

先区分标题、说明与署名在照片副本中填写并保存为什么另一个查看器显示不同？交付前检查

先区分标题、说明与署名

标题用一句短语概括照片；说明补充事件、人物和场景；署名记录创作者；版权声明说明权利归属。关键词用于检索，不应替代完整说明。

标题示例
街市清晨
说明示例
摊主在清晨整理当天售卖的蔬菜。
署名示例
你的摄影署名
版权示例
填写你有权使用的版权声明。

在照片副本中填写并保存

  1. 选择已有照片，打开编辑流程。
  2. 填写标题、说明、关键词、署名和版权；共同信息可先保存成预设。
  3. 需要时逐张调整说明，再生成处理后的照片。
  4. 打开生成文件，在元数据视图中回读对应字段。

为什么另一个查看器显示不同？

不同软件可能优先读取 IPTC 或 XMP 中的不同字段，也可能没有展示全部信息。先比较同一份生成文件、同一个字段；不要仅凭缩略图或旧缓存判断是否写入成功。

交付前检查

  • 确认署名和版权归属准确，而不是照搬演示文字。
  • 确认没有把未经核实的人名、地点写入说明。
  • 测试接收方实际使用的软件和文件格式。
