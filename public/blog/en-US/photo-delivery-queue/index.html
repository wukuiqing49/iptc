Practical guide

How to check photos and deliver them to your own server

Verify the files and metadata first, then check the server connection, destination and task status. CaptionMeta does not provide hosted photo storage.

Current version 1.4.0 · 2026-11-12

Prepare a server connection

The app provides FTP, FTPS, SFTP, HTTP, SMB and WebDAV configurations. You need an authorized server, account and writable destination. Connectivity depends on your server settings.

Test a small set before the full delivery

  1. Create a server profile and check the address, protocol and destination.
  2. Test connectivity and write permissions with a non-sensitive photo.
  3. Check captions, rights and privacy information in processed photos.
  4. Add the files to the queue and inspect each task’s result.

Read the specific failure

A network interruption, incorrect credentials and a non-writable directory require different fixes. Check the error and verify the file at the server; entering the queue is not the same as successful delivery.

Protect connection details

When contacting support, share the error type and relevant steps without passwords or complete server credentials. The current demonstration covers local editing and does not demonstrate a server upload.
