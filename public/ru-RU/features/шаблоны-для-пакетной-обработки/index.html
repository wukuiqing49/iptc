Шаблоны для пакетной обработки

Повторно используйте шаблоны IPTC для группы фотографий, сохраняя индивидуальные значения.

Какую задачу она решает: При повторяющихся заданиях трудно сохранять единообразие, если одни и те же поля заново вводятся для каждой фотографии.

Что можно сделать

  • Создавать и повторно использовать шаблоны метаданных
  • Применять пакетные значения к выбранным фотографиям
  • Задавать отдельные значения, когда фотографии нужна другая подпись или поле

Доступные настройки

  • Поля шаблона, пакетные значения, значения отдельных фотографий, авторство, местоположение и настройки передачи

Поддерживаемые входные данные

  • Группа локальных фотографий и сохранённый шаблон метаданных

Результаты

  • Пакет обработанных копий с рассчитанными значениями метаданных

Процесс работы

  1. Выберите или создайте шаблон IPTC
  2. Выберите поля и фотографии для обработки
  3. Проверьте значения отдельных фотографий и запишите итоговые значения

Ограничения

  • Шаблон влияет только на настроенные поля процесса; пустые и отключённые поля не считаются заполненными.

Частые вопросы

Может ли одна фотография заменить пакетное значение?

Да. Тесты разрешения процесса подтверждают приоритет значения отдельной фотографии над настроенным пакетным значением.
