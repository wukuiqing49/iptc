Coda di consegna foto

Metti in coda le foto elaborate, consegnale tramite server configurati e controlla i risultati.

Il problema che risolve: La consegna delle foto sul campo può fallire quando file, server e stato dei tentativi sono gestiti separatamente.

Cosa puoi fare

  • Mettere in coda i file fotografici elaborati
  • Supportare client configurati FTP, FTPS, SFTP, HTTP, SMB e WebDAV
  • Riprovare alcuni errori HTTP temporanei e conservare i risultati delle attività

Opzioni disponibili

  • Profili server FTP, FTPS, SFTP, HTTP, SMB e WebDAV

Input supportati

  • File fotografici locali elaborati e profilo server configurato

Output

  • Attività di caricamento in coda con risultato riuscito o fallito

Flusso di lavoro

  1. Configura un profilo del server di consegna
  2. Scegli le foto elaborate e aggiungile alla coda
  3. Controlla la coda, riprova gli errori idonei e consulta la cronologia

Limitazioni

  • La consegna richiede un server raggiungibile e credenziali configurate dall’utente. L’app non offre spazio fotografico ospitato.

Domande frequenti

Quali protocolli di consegna sono supportati?

Il modulo di caricamento include client e modelli di configurazione per FTP, FTPS, SFTP, HTTP, SMB e WebDAV.
